# KFS CNN Recognition — Хэрэглэх заавар

## Суулгах (Install)
```bash
pip install torch torchvision opencv-python pillow numpy
```

---

## 3 алхамт ажлын дараалал

### 1. Өгөгдөл цуглуул
```bash
python kfs_collect.py
```
- `← →` товчоор анги (тэмдэгт) сонгоно
- `SPACE` дарахад тухайн KFS-ийн **5 зураг** нэгэн зэрэг хадгалагдана (бага зэрэг өнцгийн зөрүүтэй)
- Нэг тэмдэгтэд **дор хаяж 30 зураг** цуглуул (50+ байвал илүү сайн)
- `Q` дарж гарна

Хавтасны бүтэц:
```
kfs_data/
  char_01/    ← R2 KFS тэмдэгт 1
  char_02/
  ...
  fake_01/    ← Хуурамч KFS тэмдэгт 1
  ...
  background/ ← KFS биш зураг
```

**Анхаарах зүйл:**
- Өөр өөр гэрэлтүүлэг, өнцгөөс зураг авна
- KFS хайрцгийн тал бүрийн зургийг тус тус авна

---

### 2. Загвар сурга
```bash
python kfs_train.py
```
- CPU дээр ~5-10 минут, GPU байвал ~1 минут
- `★` тэмдэглэгдсэн эпохийн загвар `kfs_model.pt` болж хадгалагдана
- `Val Acc` 90%+ хүрвэл сайн гэж үзнэ

---

### 3. Бодит цаг recognition
```bash
# Камераас бодит цаг
python kfs_recognize.py

# Нэг зураг шалгах
python kfs_recognize.py --image test.jpg

# Accuracy шалгах
python kfs_recognize.py --eval
```

## kfs_classes.json засах

`kfs_collect.py` анх ажиллахад `kfs_classes.json` үүсдэг.  
Тэмдэгтүүдийн нэрийг өөрийн тохиргоонд тохируулан засна:

```json
[
  "ren",    "shan", "he",   ...   // жинхэнэ 15 тэмдэгт
  "fake_ren", "fake_shan", ...   // хуурамч 15 тэмдэгт
  "background"
]
```

---

## Тохиргооны тоонууд (kfs_recognize.py)

| Утга | Тайлбар |
|------|---------|
| `CONF_THRESHOLD = 0.75` | Итгэлцэл 75%-с дээш байвал мэдэгдэнэ |
| `SMOOTH_FRAMES = 8`     | 8 фрэймийн дундажаар шийднэ |
| `CAM_INDEX = 0`         | Камерын дугаар (0, 1, 2...) |

---

## Алдааны засвар

| Алдаа | Шийдэл |
|-------|--------|
| "Загвар олдсонгүй" | `python kfs_train.py` эхлээд ажиллуул |
| Val Acc < 70% | Нэг ангид 50+ зураг нэм, дахин сурга |
| Камер нээгдэхгүй | `CAM_INDEX = 1` болгон өөрчил |
| Хайрцаг илрүүлэхгүй | Арын дэвсгэрийг цайлга, гэрэлтүүлгийг нэмэгдүүл |
